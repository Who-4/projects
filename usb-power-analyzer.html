USB Power Analyzer

Modular USB power measurement and analysis platform

← Back to Main Page

Overview

The USB Power Analyzer is meant to measure the input and output voltages and currents of low-voltage DC-DC converters to evaluate their performance. The focus of this project is to learn how to design the analog front end for a precision measurement instrument.

Goals

  • Measure voltage and current with high accuracy.
  • Create a modular hardware architecture.
  • Implement calibration procedures.
  • Have precision and accuracy comparable to bench top text equipment.
